# Planning Consolidation

Default to a read-only proposal. Require a substantially complete phase and
explicit user approval before moving artifacts.

1. Freeze original Feature, Story, optional Feature design, Story design, and
   run evidence under a dated archive.
2. Preserve every REQ, DES, UI, FD, Feature, and Story ID and map its current
   disposition.
3. Keep the concise PRD and active Core Design authoritative for current global
   intent.
4. Rebuild active routing around independently verifiable capabilities and
   remaining work.
5. Do not rewrite code, tests, migrations, or historical Story bodies.

Report archive location, mapping coverage, unresolved evidence, and context
reduction.
